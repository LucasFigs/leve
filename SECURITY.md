# Segurança

Para relatar uma vulnerabilidade, escreva para **lucasfig.oliv@gmail.com**. Inclua a versão/commit, os passos mínimos para reproduzir e o impacto observado. Não envie senhas, tokens ou dados de outras pessoas.

Evite publicar detalhes exploráveis em issues antes de conversar com o responsável. Use contas e dados próprios de teste e não realize testes destrutivos contra a instância pública.

O projeto está em desenvolvimento. Correções são feitas na versão atual da branch principal; não há compromisso de manutenção de versões antigas ou prazo garantido de atendimento.

Os controles e as limitações estão em [docs/seguranca.md](docs/seguranca.md). Testes automatizados e revisões reduzem riscos, mas não certificam ausência de vulnerabilidades. O código do repositório e uma instância hospedada podem estar em versões diferentes.
