# Imagens para o LinkedIn

Artes em PNG, 1080 × 1350 pixels, geradas a partir da interface real do Leve em ambiente local sem Supabase, com dados fictícios. A data das capturas é 05/11/2026. Não contêm dados de conta ou tarefas pessoais.

## Ordem sugerida

1. `01-um-dia-mais-leve.png`: tela Hoje com lista compacta, progresso, tarefa, compromisso e hábitos.
2. `02-da-captura-ao-plano.png`: captura em português e resultado na agenda interna do Leve. Não representa a integração Google Agenda. O exemplo foi reconhecido como 06/11/2026, 14h, 45 minutos.
3. `03-um-passo-de-cada-vez.png`: visualização de tarefa com um passo concluído e o próximo destacado.
4. `04-habitos-que-cabem-na-rotina.png`: calendário e histórico visual de um hábito, opcional para o post.

As capturas sem moldura estão em `capturas/`. O arquivo `leve-linkedin.zip` contém somente as quatro artes prontas para anexar ao post. Não publicar este README como parte do texto.
